# Ex-post trust — relocating consent without losing it (2026-07-30)

USER QUESTION (2026-07-30, after watching a free-running build fleet outpace
the gated pipeline all night): "when claude code is able to freestyle, shit
gets done within a reasonable amount of time — how can we alter our pipeline
without giving up trustworthiness?"

## Why the freestyle night was fast — and still trustworthy

Trust was RELOCATED, not skipped: no act asked permission; every act was
adversarially verified AFTER (independent verifier, mutation probes,
evidence-only reporting to the human); the hard boundaries were exactly
attestation (human sign-off), outward/irreversible acts (push), and human
intent. Reversibility (worktrees) made everything else free; the merge was
the checkpoint. Ex-post + evidence-based beats ex-ante + consent-based on
throughput at equal (arguably higher) assurance — WHEN reversibility and
verification are real.

## The principle

**Gate by irreversibility and attestation, never by step.**

## Ruling docket

- **R-a — standing run-consent as the DEFAULT mode.** One typed grant at
  experiment start (spend envelope, caps, expiry, cmd_sha binding — the R1
  substrate as-is); per-block y only when an act crosses a boundary the
  grant did not name. Overnight stops being a special case.
- **R-b — reversible legs ungate in code.** Widen the R5
  speculation-eligibility law until the gate census is exactly: spend
  crossings not covered by the grant, attestations, outward acts
  (export/publish/push). Idempotent + content-keyed is the eligibility
  test, proven per-verb by fire tests (the existing law).
- **R-c — parks carry results, never requests.** Every boundary the chain
  reaches has already run its reversible successor work speculatively; the
  brief presents evidence ("canary green, staged, array composed — one y
  launches"). The S1-meld generalized chain-wide.
- **R-d — adversarial verification as a product primitive.** Generalize
  verify-relay/claim-check: before an output is citable, an independent
  adversarial pass attacks the evidence chain (basis checks, recompute
  locks, mutation-style probes where applicable) and its verdict is
  journaled beside the result.
- **R-e — judgment legs ride the agent-actor park** (P2.a, landed): code
  sequences, the LLM judges at named non-consent parks, disclosure
  journaled; the human holds attestation + spend only.

## Invariants that never move (the trust floor)

Typed attestation authorship + the utterance log; append-only journal;
`append-decision` always human-prompted (the consent-forward hook hard-codes
it); caps/expiry/spec-binding on all standing authority; every automated act
disclosed in the morning brief; reviewer≠author; the determinism doctrine.
These ARE the product; everything else is throughput.
